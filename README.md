# pranavgg.me

A modern, responsive portfolio website showcasing projects, skills, and experience. Built with Next.js and modern web technologies for optimal performance and user experience.

## Tech Stack

### Frontend
- **Framework**: Next.js 16.0.10
- **React**: 19.1.1
- **Language**: TypeScript 5.9.2
- **Styling**: Tailwind CSS 4.1.12, CSS
- **Icons**: Lucide React 0.540.0
- **Animations**: Framer Motion 12.23.12

### Development Tools
- **Linting**: ESLint 9.33.0
- **Type Checking**: TypeScript 5.9.2
- **PostCSS**: Tailwind CSS PostCSS 4.1.12
- **Bundler**: Turbopack
